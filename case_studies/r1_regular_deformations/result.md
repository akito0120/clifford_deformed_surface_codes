# R1: Regular Clifford deformations under biased noise

A usefulness case study (RQ3). It adds 246 periodic deformations of the rotated surface code as a plugin, screens them against XZZX at code capacity, and compares the best two at circuit level under identical conditions.

## Codes

- [codes.py](codes.py) gives each data qubit (c, r), at column c and row r from the top left, a label from a periodic pattern:
  - I: undeformed; a Z error stays Z on the CSS code.
  - H: Hadamard; a Z error acts as X.
  - S: √X (`SQRT_X`, not the phase gate); a Z error acts as Y.
- Under Z-biased noise with p_X = p_Y, these three labels cover every distinct deformation of a qubit.
- The lattice, the qubit count and the 4-step schedule are the CSS code's. Only the Pauli each check measures on a deformed qubit changes.
- There are six families. Data qubit (c, r) takes the k-th letter of the name's suffix (see [patterns](results/patterns/patterns_overview.pdf), generated by [plot_patterns.py](plot_patterns.py)):

| Family | k | Codes |
|---|---|---|
| cell | 2 (r mod 2) + (c mod 2): a 2×2 unit cell, named `cell_<top row>_<bottom row>` | 78 |
| row3 | c mod 3 | 24 |
| col3 | r mod 3 | 24 |
| diag3 | (r + c) mod 3 | 24 |
| anti3 | (r − c) mod 3 | 24 |
| diag4 | (r + c) mod 4 | 72 |

- A pattern equal to a built-in code (all I: `rotated_surface`; the checkerboard: `xzzx`; all S: `xy`) or to an earlier pattern is not registered. That leaves 246 new codes, 249 with the built-ins.
- The two codes taken to circuit level, top-left corner (r = 0–3, c = 0–5):

```
cell_II_SH     anti3_ISH
I I I I I I    I H S I H S
S H S H S H    S I H S I H
I I I I I I    H S I H S I
S H S H S H    I H S I H S
```

## Setup

- Noise: `biased`, η = 100. Decoder: `bp` (belief-matching). Bases X and Z.
- Validation: all 249 codes pass the seven code and circuit checks at d = 3, 5, 7, 9 ([validation.json](results/screen_eta100/validation.json)). The screen's d = 11 is not covered.

**Stage 1, code-capacity screen** ([config_screen_eta100.yaml](config_screen_eta100.yaml))
- All 249 codes, p = 0.15, d = 7, 9, 11
- Each point ran to 3000 errors or 10⁵ shots
- Ranking ([summarize_screen.py](summarize_screen.py)): at each d, the ratio of XZZX's p_L to the code's, each in its worse basis. A code's score is its smallest ratio over d, so a score above 1 means it beats XZZX at every distance.

**Stage 2, circuit level**: XZZX against cell_II_SH (rank 1) and anti3_ISH (rank 3)
- Configs: [config_xzzx_vs_anti3_ISH_circuit_level_v2.yaml](config_xzzx_vs_anti3_ISH_circuit_level_v2.yaml) and [config_cell_IISH_circuit_level.yaml](config_cell_IISH_circuit_level.yaml). They differ only in `codes` and the output directory.
- d rounds, d = 3, 5, 7
- Threshold sweep: p = 1.0–2.0% (10 points)
- Suppression sweep: p = 1%, target p_L = 10⁻¹²
- Each point ran to 5000 errors (the 5 × 10⁵-shot limit was never reached)

### Screen

From [screen_summary.csv](results/screen_eta100/screen_summary.csv); p_L in the worse basis:

| Rank | Code | p_L, d = 7 / 9 / 11 (× 10⁻³) | Ratio to XZZX, d = 7 / 9 / 11 |
|---|---|---|---|
| 1 | cell_II_SH | 6.03 / 2.81 / 1.65 | 2.70 / 3.47 / 3.50 |
| 3 | anti3_ISH | 8.08 / 4.66 / 2.76 | 2.02 / 2.09 / 2.09 |
| 25 | xzzx | 16.3 / 9.74 / 5.77 | 1 |
| 193 | xy | 62.4 / 58.3 / 55.6 | 0.26 / 0.17 / 0.10 |
| 248 | rotated_surface | 282 / 320 / 333 | 0.06 / 0.03 / 0.02 |

- 24 new codes beat XZZX at every distance, 19 of them by more than 2σ at each d. They come from cell (11), anti3 (5), diag3 (5) and diag4 (3). No row3 or col3 code does (best scores 0.67 and 0.70).
- Up to lattice symmetry (180° rotation, or 90° rotation with X and Z swapped), the 24 form 12 classes, and equivalent codes give the same p_L within statistical error. Ranks 2 and 4 are the partners of ranks 1 and 3.

## Discussion

- **The code-capacity advantage does not carry over directly.** At circuit level, both codes have a higher worse-basis p_L than XZZX at every simulated point (p = 1–2%, d ≤ 7). Their order also flips: cell_II_SH, first in the screen, falls behind anti3_ISH, and its weak basis changes from Z to X.
- **The deformed codes gain where XZZX is weak.** XZZX's Z basis has the lowest threshold and the slowest suppression of the six series, and it sets XZZX's footprint. anti3_ISH is balanced between its two bases.
- Thresholds may go up with the distance. Samples from higher distances are required to see where the real therehold converges.
- Not tested: other values of η and p in the screen, and d > 7.

## RQ3

**Yes, within the scope tested.**
- Adding 246 deformations took one plugin of about 60 lines and no change to the framework. The framework validated each code and built its circuits with different noise models.
- Comparing them with XZZX under identical conditions took one config per stage. The comparison showed what a single noise level would miss: the best code at code capacity is not the best at circuit level.
- Ranking the 249 codes and drawing the patterns needed case-study scripts, because the framework analyzes each code on its own and does not compare codes.
